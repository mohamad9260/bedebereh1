# راهنمای نصب و راه‌اندازی پنل مدیریت و وب‌سرویس «بده بره» در cPanel

این پکیج شامل **پنل مدیریت وب (Admin Dashboard)**، **پایگاه داده MySQL** و **وب‌سرویس‌های RESTful API** برای اتصال به اپلیکیشن موبایل و درگاه پرداخت زرین‌پال است.

---

## 📁 ساختار فایل‌های پنل مدیریت

```text
web_admin_cpanel/
├── database.sql           # ساختار کامل جداول و دیتابیس MySQL (کاربران، آگهی‌ها، تراکنش‌ها، کلمات ممنوعه)
├── config.php             # فایل تنظیمات اتصال به دیتابیس و توابع امنیتی
├── login.php              # صفحه ورود امن مدیران
├── logout.php             # خروج از سیستم
├── header.php & footer.php# قالب واکنش‌گرا و منوهای راست‌چین (RTL)
├── index.php              # داشبورد اصلی با کارت‌های آماری، درآمد کل و دسترسی‌های سریع
├── users.php              # مدیریت کامل کاربران، مسدودسازی (Ban) با درج دلیل، تغییر سطح و قفل ثبت آگهی
├── listings.php           # کارتابل تایید، رد (با درج علت) و حذف آگهی‌های ثبت‌شده
├── categories.php         # مدیریت دسته‌بندی‌ها و قفل‌گذاری بخش‌ها جهت جلوگیری از ثبت آگهی
├── content_control.php    # داشبورد کلمات ممنوعه (Blacklist) و اسکنر هوشمند متن
├── financial.php          # گزارشات مالی زرین‌پال، آمار فروش اشتراک‌ها و خروجی اکسل (CSV)
├── settings.php           # تنظیم کدرهگیری (Merchant ID) زرین‌پال، حالت آزمایشی (Sandbox) و تغییر رمز مدیر
└── api/                   # وب‌سرویس‌های اتصال اپلیکیشن اندروید
    ├── listings.php       # دریافت آگهی‌ها با تاخیر زمانی و ثبت آگهی با بررسی خودکار کلمات ممنوعه
    ├── categories.php     # دریافت لیست دسته‌بندی‌ها و وضعیت قفل بودن بخش
    ├── users.php          # ثبت‌نام، ورود و بررسی وضعیت مسدودی کاربر
    └── payment.php        # اتصال به درگاه پرداخت زرین‌پال و اعتبارسنجی بازگشت وجه (Verify)
```

## 🚀 مراحل نصب روی هاست cPanel (در کمتر از ۵ دقیقه)

### مرحله ۱: ساخت دیتابیس در cPanel
1. وارد کنترل‌پنل **cPanel** خود شوید.
2. از بخش **Databases** گزینه **MySQL Database Wizard** را انتخاب کنید.
3. یک نام برای دیتابیس انتخاب کنید (مثلاً `bedebere_db`).
4. یک نام کاربری (مثلاً `bedebere_user`) و یک رمز عبور قوی تعریف کنید.
5. در مرحله دسترسی‌ها، تیک **ALL PRIVILEGES** را فعال کرده و تایید کنید.

### مرحله ۲: ایمپورت فایل دیتابیس (`database.sql`)
1. در cPanel وارد ابزار **phpMyAdmin** شوید.
2. از ستون سمت چپ، دیتابیس ساخته‌شده را انتخاب کنید.
3. از تب بالای صفحه روی دکمه **Import** کلیک کنید.
4. فایل `web_admin_cpanel/database.sql` را انتخاب کرده و روی **Go / Import** در پایین صفحه کلیک نمایید.

### مرحله ۳: آپلود فایل‌ها به هاست
1. در cPanel وارد **File Manager** شوید.
2. وارد پوشه `public_html` (یا ساب‌دامین اختصاصی مانند `admin.yoursite.com`) شوید.
3. تمام فایل‌های این پوشه (`web_admin_cpanel`) را آپلود و اکسترکت نمایید.

### مرحله ۴: تنظیم اطلاعات اتصال در `config.php`
فایل `config.php` را در File Manager ویرایش کرده و مشخصات دیتابیس را وارد کنید:

```php
define('DB_HOST', 'localhost');
define('DB_USER', 'نام_کاربری_دیتابیس_شما'); // مثلا cpaneluser_bedebere
define('DB_PASS', 'رمز_عبور_دیتابیس_شما');
define('DB_NAME', 'نام_دیتابیس_شما');       // مثلا cpaneluser_bedebere_db
define('SITE_URL', 'https://yourdomain.com/admin');
```

## 🔑 اطلاعات ورود پیش‌فرض به پنل مدیر

- **آدرس ورود:** `https://yourdomain.com/admin/login.php`
- **نام کاربری:** `admin`
- **کلمه عبور:** `admin123456_ChangeMe!`

> **نکته امنیتی:** پس از اولین ورود، حتماً از بخش **«تنظیمات درگاه و سامانه»** کلمه عبور مدیر را تغییر دهید.

## 🌟 امکانات پنل مدیریت وب

1. **مدیریت کاربران (Users & Banning):**
   - مشاهده لیست کامل کاربران، شماره تلفن و کدملی.
   - مسدودسازی دائم یا موقت با درج دلیل مسدودی.
   - غیرفعال‌سازی امکان ثبت آگهی برای کاربر خاطی.
   - ارتقای دستی سطح کاربر به طلایی یا نقره‌ای.

2. **کارتابل نظارت و تایید آگهی‌ها (Moderation):**
   - تایید و انتشار آنی آگهی‌های جدید.
   - رد آگهی همراه با ثبت دلیل رد جهت نمایش به کاربر.
   - تفکیک آگهی‌ها بر اساس هدیه رایگان، کوپن تخفیف یا درخواست یاری.

3. **قفل‌گذاری بخش‌ها (Category Lockdown):**
   - امکان متوقف‌کردن ثبت آگهی در هر دسته‌بندی خاص با یک کلیک.
   - تعیین پیام هشدار به کاربران هنگام انتخاب بخش قفل‌شده.

4. **سیستم کنترل کلمات ممنوعه و فیلترینگ (Blacklist Engine):**
   - اضافه یا حذف کلمات غیراخلاقی، کالاهای غیرمجاز، قمار، دارو و سلاح.
   - امکان تست و اسکن هوشمند متن در محیط شبیه‌ساز.

5. **تنظیمات درگاه زرین‌پال و گزارشات مالی:**
   - ثبت `Merchant ID` ۳۶ کاراکتری زرین‌پال.
   - قابلیت فعال‌سازی حالت تست (Sandbox).
   - جدول کلیه تراکنش‌ها با کد پیگیری بانکی و خروجی مستقیم به فایل Excel / CSV.
   - مدیریت قیمت اشتراک‌های نقره‌ای و طلایی و زمان تاخیر نمایش برای کاربران رایگان.
